> Phase : de l'idée au prototype testable, avant le développement

## En une phrase

Un réseau social pour les développeurs africains, relié à GitHub et GitLab.

**GitHub et GitLab sont l'endroit où l'on travaille. Notre plateforme est l'endroit où l'on se montre, où l'on se retrouve et où l'on se fait reconnaître.**

## Contexte

Compétition dont le thème est : *« Construire la plateforme d'échange africaine, pour les devs, par les devs »*.

## Décisions déjà prises

- Cible principale : étudiants et développeurs juniors d'Afrique francophone (départ : Burkina Faso et pays voisins).
- Public secondaire : passionnés qui construisent avec l'IA.
- La plateforme **complète** GitHub et GitLab, elle ne les concurrence jamais.
- C'est un **vrai réseau social** : abonnés, publications, commentaires, likes.
- Pas d'éditeur de code en ligne, pas de gestion de tickets, pas de fork ou de PR créés par la plateforme.
- L'utilisateur garde ses outils et son IA pour le travail sur le code.
